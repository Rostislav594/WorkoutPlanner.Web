# GymPlanner UI workflow

1. Inspect existing screens and shared CSS before designing.
2. Reuse established spacing, radii, typography, shadows, colors, and controls.
3. Design mobile-first and verify narrow widths.
4. Preserve readable hierarchy and touch-friendly control sizes.
5. Include relevant hover, focus, active, disabled, validation, loading, and empty states.
6. Prefer existing CSS variables and classes.
7. Keep markup accessible and keyboard-operable.
8. Avoid visual churn outside the requested area.
9. Describe visual changes and responsive behavior in the final response.
