# Wear OS — Этап 5: минимальный UI подключения часов

## Выполнено

В основном Blazor-приложении в профиле добавлен отдельный раздел «Часы».
Авторизованный пользователь может без Swagger:

- запустить создание одноразового шестизначного pairing code;
- увидеть созданный код и точное время его истечения в UTC;
- прочитать короткую инструкцию «Введите этот код на часах»;
- создать новый код, который отменяет ранее созданный;
- получить явные loading, success и error состояния.

UI напрямую переиспользует `WatchPairingService` и получает user ID только из
текущего authenticated context через `CurrentUserService`. Pairing code не пишется
в лог и по-прежнему хранится сервером только в виде hash.

## UI и доступность

- отдельный раздел не превращён в страницу управления устройствами;
- шестизначный код набран моноширинным шрифтом с tabular цифрами;
- для screen reader код озвучивается по одной цифре;
- success и error имеют семантические status/alert роли;
- во время запроса кнопка заблокирована от повторного запуска;
- узкая компоновка переводит основное действие на полную ширину.
