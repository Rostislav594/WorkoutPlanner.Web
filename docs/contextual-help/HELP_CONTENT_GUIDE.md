# GymPlanner — Help Content Guide

## Назначение

Каждая секция справки должна быстро ответить на практический вопрос пользователя. Help — это контекстное объяснение, а не документация и не обязательный onboarding.

## Структура секции

Предпочтительный порядок:

1. короткое название действия;
2. зачем оно нужно;
3. актуальная UI-иллюстрация для сложного действия;
4. два–четыре коротких шага;
5. важное условие, только если оно действительно влияет на результат.

После секции пользователь должен понимать: что это → где находится → что нажать → какой результат ожидать.

## Текст

- Писать коротко, разговорно и без технического жаргона.
- Использовать фактические названия кнопок и разделов.
- Не описывать функции, которых нет в текущей версии.
- Не повторять очевидное ради объёма.
- Не создавать длинные вступления и цепочки из 10–15 шагов.

## Иллюстрации

Для сложной функции использовать актуальный screenshot, crop реального UI или точную code-native схему.

Можно добавлять:

- рамку вокруг целевого элемента;
- одну–две стрелки;
- мягкую локальную подсветку;
- номера коротких шагов.

Нельзя:

- использовать персонажей или маскотов;
- выдавать декоративную иллюстрацию за screenshot/график;
- показывать устаревшее расположение элементов;
- перегружать один кадр множеством указателей.

## Иконки и визуальные акценты

Иконки используются как спокойные ориентиры. Вокруг них не добавляются светящиеся рамки, трассировки или автоматически запускаемые анимации.

## Основные topics

- Workouts/Workout Details: создание плана, упражнения, количество подходов, вес каждого подхода, редактирование и суперсеты только при наличии функции.
- Today: запуск, фактические значения, завершённые подходы, таймер, завершение и сохранение результата.
- Progress: источник данных, оси, период, выбор упражнения/тренировки и интерпретация тенденции; нужны актуальные изображения реальных графиков.
- History: какие фактические данные сохраняются и как открыть результат.
- Calendar: назначение, изменение и ограничения по датам.
- Profile/Support: только фактически доступные способы связи и настройки.

## Актуальность

После изменения страницы проверить связанный Help Topic, текст, alt-текст и изображение. Если screenshot или название элемента устарели, обновить их в той же задаче. Устаревшая справка считается UI/UX-багом.
