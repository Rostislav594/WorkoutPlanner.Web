# GPlanner — First Launch и Contextual Help

## Последовательность первого запуска на Mobile

```text
Нативная заставка
→ сообщение создателя
→ экран загрузки приложения
→ регистрация / вход
→ настройка профиля
→ краткое знакомство
→ «Добро пожаловать в GymPlanner»
→ приложение
```

Сообщение создателя показывается один раз на конкретной установке приложения и сохраняется локально после нажатия `НАЧАТЬ`. Оно не зависит от аккаунта и появляется до инициализации авторизации.

## Сообщение создателя

- полностью чёрный фон;
- только плавное появление текста, без рамок, светящихся точек, трассировки и декоративных линий;
- основной текст и подпись набраны прописными буквами;
- `GPLANNER` выделяется основным цветом приложения;
- `НАЧАТЬ` использует стандартный primary button приложения;
- учитываются safe area, узкие экраны и landscape.

## Краткое знакомство

После регистрации и настройки профиля пользователь проходит четыре коротких информационных экрана. Они используют обычные иконки и UI-композиции без анимированных рамок и подсветок.

Завершение знакомства ведёт на финальный экран `Добро пожаловать в GymPlanner`. Только после этого сохраняется серверный признак завершения всего пользовательского знакомства.

## Contextual Help

Кнопка `?` сохраняется на сложных страницах и сразу открывает руководство текущего раздела.

- вокруг ярлыка нет постоянной рамки, glow или запускаемой анимации;
- сохраняются доступное имя, клавиатурный фокус, Escape и возврат фокуса после закрытия;
- Desktop использует dialog, Mobile — адаптивный sheet;
- тексты, шаги и иллюстрации остаются привязаны к фактической функциональности страницы.

## Состояние

- локальный признак сообщения создателя: одна установка приложения;
- серверный признак завершения знакомства: один пользователь;
- повторное открытие знакомства из профиля сбрасывает только серверный признак;
- старые completion tokens продолжают читаться для совместимости.

## Удалённая система

Прежняя декоративная система подсветки, её компоненты, режимы, JavaScript, CSS-токены, трассировки, частицы и связанные анимации удалены и не должны использоваться повторно.
