# GPlanner — First Launch и Contextual Help

## Последовательность первого запуска на Mobile

```text
Нативная заставка
→ сообщение создателя
→ экран загрузки приложения
→ регистрация / вход
→ настройка профиля
→ краткое знакомство
→ «Добро пожаловать в GymPlanner»
→ приложение
```

Сообщение создателя показывается один раз на конкретной установке приложения и сохраняется локально после нажатия `НАЧАТЬ`. Оно не зависит от аккаунта и появляется до инициализации авторизации.

## Сообщение создателя

- полностью чёрный фон;
- только плавное появление текста, без рамок, светящихся точек, трассировки и декоративных линий;
- основной текст и подпись набраны прописными буквами;
- `GPLANNER` выделяется основным цветом приложения;
- `НАЧАТЬ` использует стандартный primary button приложения;
- учитываются safe area, узкие экраны и landscape.

## Краткое знакомство

После регистрации и настройки профиля пользователь проходит четыре коротких информационных экрана. Они используют обычные иконки и UI-композиции без анимированных рамок и подсветок.

Завершение знакомства ведёт на финальный экран `Добро пожаловать в GymPlanner`. Только после этого сохраняется серверный признак завершения всего пользовательского знакомства.

## Contextual Help

На Mobile кнопка `?` есть только на страницах «Сегодня» и «Тренировки». С остальных мобильных страниц она убрана. В вебе (админке) текстовые руководства остаются без изменений.

### Mobile: интерактивное обучение «Сегодня»

`?` на «Сегодня» запускает не текст, а демонстрацию (~115 с) на настоящих элементах страницы: свободная тренировка → первое упражнение через окно (выбор, подходы, вес и повторения) → ещё два упражнения одним нажатием «Добавить упражнение», без окна → суперсет → изменение отдыха → выполнение с таймерами → завершение удержанием → «Тренировка завершена».

- середина экрана чистая, лёгкое размытие и затемнение только по краям (`.tutorial-veil`: `backdrop-filter` с радиальной маской); элемент, с которым идёт работа, вычитается из маски вторым слоем, чтобы край его не размыл, — без рамок и подсветки зоны нажатия;
- нажатия показывает рука `pan_tool_alt` из Material Symbols, как остальные иконки приложения;
- подсказка шага — облачко над целью у руки: держится ~2 с и гаснет, итоговое «Готово!» остаётся до конца; пока цель закрыта открывшимся окном или исчезла, облачко прячется; у полей в фокусе всё поле с подписью (у подходов — весь блок «Подход N»), чтобы облачко не закрывало подпись;
- «Пропустить» на непрозрачном фоне: под полупрозрачным в WebView читались подписи нижнего меню;
- сценарий вызывает те же обработчики, что и кнопки (`Today.Tutorial.cs`), прожектор лишь показывает, куда «нажали» (`wwwroot/js/todayTutorial.js`, `TutorialSpotlight`);
- на время обучения страница работает с `TutorialWorkoutBackend` вместо API и не сохраняет сессию тренировки: сервер, офлайн-очередь и часы ничего не получают;
- идущая настоящая тренировка откладывается вместе с отметками и таймерами и возвращается после обучения;
- ускорены только таймеры отдыха (любой идёт ~3 с) и удержание «Завершить» с его анимацией (вдвое короче); остальные шаги идут в спокойном темпе, чтобы их можно было запомнить;
- «Пропустить» и системная «Назад» прерывают обучение в любой момент;
- элементы, которые подсвечивает сценарий, помечены `data-tour`.

### Текстовое руководство (веб и «Тренировки»)

- вокруг ярлыка нет постоянной рамки, glow или запускаемой анимации;
- сохраняются доступное имя, клавиатурный фокус, Escape и возврат фокуса после закрытия;
- Desktop использует dialog, Mobile — адаптивный sheet;
- тексты, шаги и иллюстрации остаются привязаны к фактической функциональности страницы.

## Состояние

- локальный признак сообщения создателя: одна установка приложения;
- серверный признак завершения знакомства: один пользователь;
- повторное открытие знакомства из профиля сбрасывает только серверный признак;
- старые completion tokens продолжают читаться для совместимости.

## Удалённая система

Прежняя декоративная система подсветки, её компоненты, режимы, JavaScript, CSS-токены, трассировки, частицы и связанные анимации удалены и не должны использоваться повторно. Прожектор обучения «Сегодня» — отдельный механизм, сделанный по прямому запросу (2026-10-01): он работает только во время демонстрации и не оставляет постоянных рамок или свечения на страницах.
